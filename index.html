03 / Engineering Philosophy

The Anti-Slop Code Standards

Real software design is defined by what you choose not to do.

Anti-Pattern (AI Slop) Craft Standard Reasoning
transition: all 300ms transition: transform 150ms var(--ease-out), opacity 150ms linear Specifying properties prevents unexpected jank on layout redraws and color shifts.
transform: scale(0) transform: scale(0.96); opacity: 0 Nothing appears from a zero-dimension void; subtle scales maintain spatial orientation.
Slow command palette open Instant Raycast-style opening Keyboard-initiated actions repeat 100+ times/day. Zero animation keeps muscle memory fluid.
Generic purple-cyan gradient blobs Disciplined obsidian neutrals & precise 1px borders Cosmetic glow effects distract from typographic clarity and core product utility.
Fake marketing statistics strips Verified facts and functional code Generic strips ("99.8% satisfaction") are the definitive copy tell of synthetic templates.
